# F2P2 - Fantastic Framework & Practical PHP

F2P2 is a lightweight PHP framework based on the MVC coding method.

## Description

F2P2 makes it easier to create an application or website in PHP. Inspired by Symfony, it allows database management and easier use of database entities. It works based on a CLI which manages the project. It also provides some other features like forms, email and languages.
